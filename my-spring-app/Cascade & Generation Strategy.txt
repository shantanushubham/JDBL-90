Cascade Types
1. PERSIST -> Saves the data
    @OneToMany(cascade = CascadeType.PERSIST)

    Order order = new Order();
    OrderItem item = new OrderItem();

    order.getItems().add(item);

    entityManager.persist(order);

    * Saves the child automatically
    * Does NOT cascade remove

2. REMOVE -> Remove the data

    entityManager.remove(order);

    Delete from Order Item and then delete from order

    Warning: Never use REMOVE on @ManyToOne relations

3. REFRESH (rarely used)

    entityManager.refresh(order);


4. DETACH

    entityManager.detach(order);

5. ALL



Generation Strategy:
1. IDENTITY   | DB             | Medium | Auto-increment
2. SEQUENCE   | DB + Hibernate | Fast | DB Sequence
3. TABLE      | Table          | Slow | Uses Table | Not used anymore
4. AUTO       | Depends on DB  | Depends on DB |
5. UUID       | App            | Good | Generated by Java
